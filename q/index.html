Ghost Privacy Policy

Last updated: 28 September 2026

This policy describes how the Discord application Ghost (“the Bot”, “we”) handles data when it is added to a Discord server. Ghost is a server management bot used for member welcome messages, verification, and role assignment.

1. Data we collect

Ghost only processes data required for those features:

  • Discord user ID
  • Discord server (guild) ID
  • Member roles and join/leave timestamps
  • Server configuration set by the server owner or administrators (welcome channel, roles to assign or remove)

Ghost does not collect message content, email addresses, phone numbers, IP addresses, passwords, tokens, payment data, or user presence/status (online, idle, do not disturb).

2. Why we collect it

Data is used only to:

  • Detect when a member joins or leaves a server
  • Send a welcome or leave message in the configured channel
  • Assign or remove roles as configured by server staff
  • Look up a member by ID when a server administrator uses the management panel

Ghost uses the Guild Members privileged intent for join/leave events and member lookups. It does not use Message Content or Presence intents.

3. Storage and retention

  • Member IDs and role state are kept only while the Bot remains in that server and the related feature is enabled.
  • Data is stored on the Bot operator’s private server and is not a public database.
  • If the Bot is removed from a server, or the server owner asks for deletion, that server’s data is deleted within 24 hours.
  • Message text is not stored because message content is not read.

4. Sharing

Ghost does not sell, rent, or share user data with third parties. Data is not transferred to other Discord servers or used for advertising. Data may be disclosed only if required by law.

5. Access and deletion

A server owner or administrator can request deletion of that server’s data by contacting the Bot operator. Users may also ask Discord to exercise their platform privacy rights through Discord’s own tools.

6. Security

Access to the Bot’s hosting and configuration is limited to the operator. API credentials are stored privately and are not logged. Data is not published in public channels or files.

7. Children

Ghost is intended for Discord servers and does not knowingly collect personal data from children independent of Discord’s own platform rules.

8. Changes

If this policy changes, the date at the top of this page will be updated.

9. Contact

For privacy questions or deletion requests, contact the Ghost bot operator through the support server or the email listed on the Bot’s Discord application page.
